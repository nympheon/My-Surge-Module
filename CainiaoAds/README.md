# 菜鸟净化

[安装模块](https://raw.githubusercontent.com/nympheon/My-Surge-Module/main/CainiaoAds/CainiaoAds.sgmodule)。要求 Surge Mac 5.9.0+ / iOS 5.14.0+，启用 Rewrite、Scripting、MITM 并信任自己的证书。完整保留菜鸟与支付宝小程序的选定净化，包括我的页资产/钱包/会员入口、首页待办/福利与搜索推荐，属于完整 UI 净化。

上游 ddgksf2013；[逐条审计](AUDIT.md)说明 13 条映射、四个 JSON 分支和 MTop 错误透传。AMDC 脚本独立归属本模块。上游另有未被配置启用的脚本分支，本模块没有激活它们。

本机真实 jq 差分、数字精度、原生 Surge 配置检查和 AMDC 测试通过；未执行卸载重装、在线配置变更或 iOS/全应用验收。main 安装链接需发布后才会包含本次更新。
